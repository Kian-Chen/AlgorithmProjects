#   `separate`任务

## 任务描述

给定一系列数字，要求将其分为两个部分，使得两部分之和之差最小

## 算法描述

### Brute-Force 算法

此算法暴力遍历所有可能的子集，计算每个子集的元素和，并计算其与总和的差的绝对值，然后找到使得差值最小的子集。在遍历方法上，使用了位运算来生成所有可能的子集，然后遍历每个子集，计算其元素和以及与总和的差的绝对值，最后找到差值最小的子集。

### DP 算法

此算法使用动态规划的方法，观察到此问题类似于目标值为$\frac{\mathrm{sum}}{2}$的$0-1$背包问题，用类似的方法可以建立状态转移方程

$$\mathrm{dp}[i][j] = \max(\mathrm{dp}[i-1][j], \mathrm{dp}[i-1][j-\mathrm{nums}[i]] + \mathrm{nums}[i])$$

## 时间复杂度分析

测试数据分别是10、20、30、40长度的数据序列，由于当测试数据规模为30时使用Brute-Force算法的时间过长，故仅仅展示前两种规模的耗时对比，做表如下：

| Algorithm                 | Time (ms) |
| ------------------------- | --------- |
| DPSolution (n=10)         | 7.8965    |
| BruteForceSolution (n=10) | 1.4512    |
| DPSolution (n=20)         | 27.7666   |
| BruteForceSolution (n=20) | 2187.45   |

可以看到虽然数据规模相对较小时Brute-Force算法能较快得到结果，但是随着数据规模增加，其复杂度增长规模陡然增长，在$n=20$时，使用动态规划算法仅用时27.7666ms，而Brute-Force算法需要花费2187.45ms，相差近百倍。
